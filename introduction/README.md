##  What does 'package main' mean?

* A package is a collection of Go source code files
* Types of packages
    - **Executable** -> Generates a file that we can run. The `package main` declaration is specifically used to create executable packages.
    - **Reusable** -> Contains code that can be used as helpers or shared across different parts of a project
